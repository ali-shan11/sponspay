# SponsPay WebApp - Project Brief

## Project Overview
SponsPay WebApp is an Angular-based frontend application that serves as the marketing and user interface for the SponsPay platform - a service designed to help YouTube content creators maximize their revenue through local payment options and enhanced fan engagement features.

## Core Purpose
Enable YouTube creators to:
- Accept payments from fans in countries with limited credit card usage
- Bypass international payment restrictions
- Increase revenue through local payment methods
- Enhance fan engagement with new digital products

## Target Audience
- YouTube content creators (especially livestreamers)
- Creators with international audiences
- Creators in regions with currency restrictions
- Non-monetized YouTube creators

## Key Business Goals
1. **Expand Payment Access**: Enable fans worldwide to support creators using local payment methods
2. **Increase Creator Revenue**: Capture previously inaccessible revenue from fans unable to use credit cards
3. **Enhance Engagement**: Provide innovative digital products to boost fan-creator interaction
4. **Global Rollout**: Phase I targets 19 countries, starting with 4 initial markets

## Technical Scope
- Marketing website with landing page
- Contact form integration
- Responsive design with Bootstrap
- Internationalization support (French localization ready)
- Integration with backend API for contact submissions

## Success Criteria
- Clear communication of value proposition to creators
- Easy registration/contact process
- Professional, engaging user interface
- Scalable architecture for future features
- Successful API integration for contact forms
